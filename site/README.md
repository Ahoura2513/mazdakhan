# ریاضی روزمره

سایت آموزش ریاضی زندگی روزمره (HTML + CSS + JavaScript خالص، بدون نیاز به نصب چیزی).

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید. فونت‌ها داخل پوشه‌ی `fonts/` هستند و اینترنت لازم نیست.

## ساختار
```
site/
├── index.html      صفحه‌ی اصلی
├── css/style.css   همه‌ی استایل‌ها (رنگ‌ها و تم روشن/تیره در بالای فایل)
├── js/main.js      تم، منوی موبایل، تخفیف‌یاب، ترفندها، انیمیشن اسکرول
├── fonts/          Vazirmatn (متن) و Lalezar (تیترها)
└── favicon.svg
```

## وضعیت
فعلاً فقط **ظاهر** ساخته شده است. محتوای درس‌ها (آموزش، مثال و نمونه‌سؤال) بعد از تأیید ظاهر اضافه می‌شود.
