# ریاضی روزمره

سایت آموزش ریاضی زندگی روزمره به زبان ساده (HTML + CSS + JavaScript خالص، بدون نیاز به نصب چیزی).

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید. فونت‌ها داخل پوشه‌ی `fonts/` هستند و اینترنت لازم نیست.

## ساختار
```
riazi-rooz/
├── index.html          صفحه‌ی اصلی (موضوع‌ها، تخفیف‌یاب، ترفندها)
├── lessons/            یک صفحه برای هر موضوع
│   ├── basics.html       ۱. پایه‌ها: کسر، اعشار و چهار عمل
│   ├── percent.html      ۲. درصدها و تخفیف‌ها
│   ├── ratio.html        ۳. تناسب و قاعده سه‌تایی
│   ├── estimation.html   ۴. تخمین ذهنی و سرانگشتی
│   ├── geometry.html     ۵. هندسه کاربردی
│   ├── stats.html        ۶. آمار و احتمال مقدماتی
│   ├── money.html        ۷. پول و حساب‌وکتاب شخصی
│   └── units.html        ۸. واحدها، زمان و سرعت
├── css/style.css       همه‌ی استایل‌ها (رنگ‌ها و تم روشن/تیره در بالای فایل)
├── js/main.js          تم، منو، تخفیف‌یاب، ترفندها، بررسی جواب تمرین‌ها و ذخیره‌ی پیشرفت
├── fonts/              Vazirmatn (متن) و Lalezar (تیترها)
└── favicon.svg
```

## درس‌ها
هر موضوع ۴ زیردرس دارد (روی هم ۳۲ زیردرس، ۶۴ مثال حل‌شده و ۱۴۴ تمرین). هر زیردرس چهار بخش دارد:

1. **ببین**: توضیح ساده با مثال واقعی
2. **حل‌شده**: دو نمونه‌سؤال با راه‌حل گام‌به‌گام
3. **خودت امتحان کن**: تمرین‌هایی که جوابشان همان لحظه بررسی می‌شود (با راهنمایی و راه‌حل)
4. **ترفند سرانگشتی**: یک میان‌بر ذهنی

## افزودن یا تغییر تمرین
هر تمرین یک `div.exercise` است. جواب درست در ویژگی‌ها نوشته می‌شود و `main.js` کادر جواب را خودش می‌سازد:

```html
<!-- جواب عددی؛ data-tol اختلاف مجاز است (اختیاری) -->
<div class="exercise" id="p1-q1" data-answer="6500" data-unit="تومان" data-hint="یک صفر بردار.">…</div>

<!-- جواب تقریبی (برای تمرین‌های تخمین) -->
<div class="exercise" id="e1-q3" data-min="2800" data-max="3300">…</div>

<!-- چندگزینه‌ای؛ data-correct شماره‌ی گزینه‌ی درست از صفر -->
<div class="exercise" id="b2-q1" data-choices="۳/۶|۲/۵|۴/۶" data-correct="0">…</div>
```

`id` هر تمرین باید یکتا باشد، چون پیشرفت با همان در مرورگر (localStorage) ذخیره می‌شود.
